# Certificados raiz da Apple

A API confere as compras da App Store (StoreKit 2) contra os certificados raiz da Apple.
Baixe **AppleRootCA-G3.cer** em https://www.apple.com/certificateauthority/ e coloque
nesta pasta (ou aponte `APPLE_ROOT_CERTS_DIR` para outra). São certificados públicos:
podem ir para o repositório.
